# World Profiles 1.0

A saved profile is JSON. Supply a version, a seed (unsigned 32-bit integer), a look, a biome, a weather state, local solar time in hours [0, 24), and a quality tier. The solar clock uses day 80 at 42° N. The six look definitions are editable in `modules/weather/world-looks.json`. Looks change optical properties. Sea state controls the wave spectrum. Choose clear, mixed, overcast or squall independently of time and art direction.

Create a fresh scene with `await createLuminaWorld(profile, {canvas})`, position its camera and call `engine.start()`. Omitting the canvas mounts an owned canvas in the document. Existing callers can still pass their previous engine options. Patch look, weather, time or quality on the returned world. Overrides take precedence over a palette. A lock captures the previous effective value on a patch. Remove a lock and supply a new override to edit that value. A saved resolved profile includes its overrides, locks, modules, values and rationale. Use that resolved JSON with the native config loaders and the shared palette JSON. Godot and Unity hosts apply supported appearance values to their own materials.

For rain in an existing game use `createLuminaWorld({profileVersion:1,mode:'attach',weather:'squall'}, {scene,camera})`. Call the returned `update(dtSeconds)` from the game loop. Supply the game's WorldBus as `fields` when available. Call `dispose()` at unload. A host keeps its camera, controls, renderer, track and lighting. Save `JSON.stringify(attachment.profile)` to replay the configuration.

Choose coastal-cliffs, temperate-river-valley or dry-highlands. To supply a custom map, pass `heightmap: {size, segments, heights}` in runtime options. World distances and heights are metres, +Y is up, and the square is centered on the origin. The first row runs along +X from the -Z edge. Supply (segments + 1)² finite heights. The renderer, physical collider and query use the same triangle diagonal. Outside the supplied extent the query clamps to the boundary; the terrain collider ends at the boundary. A custom game's map is a runtime asset and must accompany the saved JSON.

Use `world.terrain.sample(x,z,reading)` with reusable `terrainReading()` storage for height, face normal, rise/run slope, moisture fraction and surfaceId. The material uses sampled substrate colors, water uses the corresponding bathymetry and vehicle raycasts hit the indexed surface. Reeds occupy shallow river margins; grass and tree roots use the same surface and shared wind as cloth. Quality scales the fraction of instances drawn while the heights and static collider keep their resolution.
