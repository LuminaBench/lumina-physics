# World Profiles 1.0

A saved profile is JSON. The [version 1 JSON Schema](world-profile-v1.schema.json) defines its fields and ranges. Supply a version, a seed (unsigned 32-bit integer), a look, a biome, a weather state, local solar time in hours [0, 24), and a quality tier. The solar clock uses day 80 at 42° N. The six look definitions are editable in `modules/weather/world-looks.json`. Looks change optical properties. Sea state controls the wave spectrum. Choose clear, mixed, overcast or squall independently of time and art direction.

Create a fresh scene with `await createLuminaWorld(profile, {canvas})`, position its camera and call `engine.start()`. Omitting the canvas mounts an owned canvas in the document. Existing callers can still pass their previous engine options. Patch look, weather, time or quality on the returned world. Overrides take precedence over a palette. A lock captures the previous effective value on a patch. Remove a lock and supply a new override to edit that value. A saved resolved profile includes its overrides, locks, modules, values and rationale. Use that resolved JSON with the native config loaders and the shared palette JSON. Godot and Unity hosts apply supported appearance values to their own materials.

Install `profile-rain` for the rain-only entry point `attachWorldRain(profile,host)`. From a full outdoor-world installation use `createLuminaWorld({profileVersion:1,mode:'attach',weather:'squall'}, {scene,camera})`. Call the returned `update(dtSeconds)` from the game loop. Supply the game's WorldBus as `fields` when available. Call `dispose()` at unload. A host keeps its camera, controls, renderer, track and lighting. Save `JSON.stringify(attachment.profile)` to replay the configuration.

Choose coastal-cliffs, temperate-river-valley or dry-highlands. To supply a custom map, pass `heightmap: {size, segments, heights}` in runtime options. World distances and heights are metres, +Y is up, and the square is centered on the origin. The first row runs along +X from the -Z edge. Supply (segments + 1)² finite heights. The renderer, physical collider and query use the same triangle diagonal. Outside the supplied extent the query clamps to the boundary; the terrain collider ends at the boundary. A custom game's map is a runtime asset and must accompany the saved JSON.

Use `world.terrain.sample(x,z,reading)` with reusable `terrainReading()` storage for height, face normal, rise/run slope, moisture fraction and surfaceId. The material uses sampled substrate colors, water uses the corresponding bathymetry and vehicle raycasts hit the indexed surface. Reeds occupy shallow river margins; grass and tree roots use the same surface and shared wind as cloth. Quality scales the fraction of instances drawn while the heights and static collider keep their resolution.

Use a second argument in seconds on `world.patch({weather:'clear', time:17.55}, 5)` for a continuous sky and grading change. A new target begins at the current blended values. In profile coordinates +Z is north. A fresh world adapts exposure to sky brightness and the overhead shelter. Independent Weather users can opt in using `autoExposure = true`. WetRoad can follow rainfall using `weatherTimeScale = 1` (real time). Higher positive values accelerate wetting and drying for time-lapse scenes. Film and standing water have distinct reservoirs, while a roof shelters the local pavement. For a road cut into a custom terrain, pass `plantable: (x,z) => boolean` to exclude the pavement from planting.

## Gallery and repeatable captures

Open **World profiles** in the local preview. Six looks share seed 721, the same headland, weather, solar angle and flight path. The look library controls sky tint, cloud lighting bands, water scatter, foam banding, vegetation color and display grading. Change the weather or solar hour separately to explore a different situation.

For release captures, build the game and serve it locally with `npx vite preview --port 5285`. From a second terminal run `node qa/capture-profiles.mjs`. The capture command uses Playwright Chromium and ffmpeg with MJPEG input and a VP9 encoder. Set `LUMINA_FFMPEG` to the encoder path and `LUMINA_PREVIEW_URL` to a different local server if needed. The ten PNG stills, ten WebM clips, manifest and playable gallery are written to `qa/output/world-profiles-1.0/`. Comparisons advance the simulation at fixed times. The separate Playwright benchmarks measure real-time playback with recording disabled.

[Procedural landscape species, density, local wind and rock dressing](25-landscapes.md) are available on built-in biomes and custom terrain.
