# Lumina Physics v1.0.0

The first public release brings 67 physics and rendering modules, four procedural rigs and 48 recipes to game developers working with coding agents. Three.js includes the full reference implementation on WebGPU and WebGL 2. Godot 4 and Unity URP include starter adapters for selected systems. Saved world profiles use `profileVersion: 1`.

- On a coastal flight, the aircraft can carve cloud, leave wingtip vapor and disturb the water beneath a low pass. On a wet road, each tire samples a different depth, throws spray and carries a film onto dry asphalt.
- Game-owned recipes can change trees, flowers, geology and materials across nine environment families and eight art directions. Shared wind, pressure, temperature and wetness connect weather, water, cloth, vegetation and fire.
- In an existing game, an agent can tune an effect or replace it at the host’s update and unload hooks. The installer previews changed paths, updates the installed selection, and preserves a reviewed local merge across future updates. [Existing-game guide](../../docs/existing-games.md)

Across 26 interaction checks, the showcase exercised scene changes, quality controls, buttons and sliders. The toolbar and panel now occupy separate layout rows. All 13 toolbar buttons were also clicked at widths of 375, 768, 1280 and 1920 pixels. The WebGL 2 cloth checks covered visible response to wind, box contacts and tearing. ## Original landscape candidate (8d82f81)

- Grow coastal cypress, oak, palm, willow, gorse, fern, heather and sagebrush from seeded branch skeletons. Wind bends individually shaped leaf sprays, grass and cattails. Instanced plants change detail with distance.
- Build a coast with sea stacks and tidal talus, a river with eroded bends and gravel bars, or grass-covered highlands with exposed shale. Rock relief uses three world-space projections, while the rendered terrain, waterlines and tire contacts share the same height samples.
- Bring the landscape into an existing game a module at a time. All six World Profiles looks and custom heightmaps are supported. Compare the biomes from hilltop and tire height in the showcase.

The first official release line uses package and catalog version `1.0.0`. Existing saved profiles retain `profileVersion: 1`. Previous development versions remain in Git history. [Integration and gallery commands](https://github.com/LuminaBench/lumina-physics/blob/main/specs/25-landscapes.md)

## Visual review

The tire-height renders show individual willow sprays, cattails, wildflowers and grass. From the hilltop, distant crowns merge into similar silhouettes and parts of the highland slopes read smooth. The 2 a.m. preset leaves little detail in the land shadows. The six-look comparison uses a shared daytime solar hour so the change in grading can be seen on the same terrain.
